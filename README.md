# Contract_Analyzer
Lawyers upload PDF contracts and get structured insights - key clauses identified, risk flagged, and recommendationa generated. The system uses Google Gemini to analyze legal documents.

1. File upload endpoint for PDF and TXT contracts
2. Text extraction from uploaded documents using PyPDF2
3. AI powered contract analysis using Google Gemini API
4. Structured output: key clauses, risk flags, overall risk level, recommendations
5. MongoDB storage for contract and analysis results
